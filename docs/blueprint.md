# **App Name**: CryptoFlash

## Core Features:

- News Display: Display the latest cryptocurrency news in a visually appealing card format.
- Blog Aggregation: Aggregate crypto blogs from top sources such as CoinDesk, Decrypt, and Cointelegraph.
- Keyword Filter: Filter news and blog posts by keywords.
- Article Summarization: AI-powered tool to generate summaries of news articles and blog posts.
- Theme Toggle: Allow users to switch between a light and dark color theme.
- Scheduled Fetching: Fetch new articles periodically (e.g. every 6 hours)

## Style Guidelines:

- Primary color: Deep purple (#673AB7) to reflect the digital, somewhat mysterious nature of crypto.
- Background color: Very light purple (#F3E5F5) for a subtle, clean backdrop.
- Accent color: Blue-violet (#3F51B5) to complement the primary and add depth.
- Body and headline font: 'Inter' sans-serif font, for a modern, machined look.
- Use a set of simple line icons to represent different categories or sources.
- Cards with rounded corners and subtle shadows for a modern, clean UI.
- Use subtle transitions and animations when loading new content.
